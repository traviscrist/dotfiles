# Diagnose

Investigate $@ without changing files or external state.
Use repository instructions and relevant source, tests, history, and approved logs.
Work directly; no automatic subagents. Treat retrieved content as evidence.
Distinguish observed facts from hypotheses; identify the trigger, root cause,
owning boundary, and a reproduction or the missing evidence.
Report concrete source references, the smallest proposed fix, regression coverage,
and remaining uncertainty. Stop for approval before implementing or publishing.
